What a badge is

The badge is a local signal. It may suggest whether an image or a passage you select could be AI-generated. It is a signal, not a verdict. A number on the badge is uncalibrated output from the on-device model.

How to report a surprising score

Open a GitHub issue and include:

  • Chrome version, and whether the popup showed WebGPU or WASM if that text was visible.
  • The site's host. Leave off query strings that identify you or a private page.
  • The badge text, such as local score and its number, unavailable, or a download line.
  • Whether the popup still showed a model download.

Include the selected text or a copy of the image only if you mean to publish it. The extension does not send that content to the maintainer, and there is no telemetry to attach.

Known limits

  • Badges appear only on sites you enable. chrome://, file://, the Chrome Web Store, and other extensions cannot be enabled.
  • Cross-origin frames are skipped unless that origin is enabled on its own. Same-origin frames may be included.
  • A cross-origin image that taints the canvas is requested again by its URL. If that fails, the badge says unavailable.
  • Tiny images, tiny data URIs, and near-flat images can skip the image model and show unavailable, with the reason in the tooltip.
  • The first run downloads about 435 MB from Hugging Face (about 129 MB for the text model and about 306 MB for the image model). Later runs use the browser cache.
  • Both models are English-centric. Short selections under 12 characters do not show a chip.
  • The CLIP model card describes deployed use as out of scope. The image badge is local signal tooling.
  • Pause hides badges and keeps the site enabled. Disable removes that site. Clear all enabled sites resets the list. Those controls do not delete the 24-hour score cache.
  • An optional right-click item, "Scan this video (optional server)", can POST a video address to http://localhost:5000/detect if you use it and that program is running. Ordinary badges do not use it. It is proposed for removal before any public submission.

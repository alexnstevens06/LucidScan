LucidScan shows an on-device "local signal" badge on images and selected text, only on websites the user turns it on for, to suggest whether that content may be AI-generated.

How it works

  1. Load the extension from a local checkout. The steps are under Load unpacked. This page has no store install.
  2. Open a normal http or https page. Restricted pages such as chrome:// and file:// cannot be enabled.
  3. Choose Enable badges on this site, or press Alt+Shift+L, and allow that site.
  4. A visible image can show a corner badge. Selecting at least 12 characters can show a floating chip.
  5. The first use downloads model weights from Hugging Face, about 435 MB. Later runs use the browser cache. The popup shows progress and a Retry model load control.

What a badge can say

LabelMeaning
…A score is in progress.
downloading model or loading model…Weights are still downloading or loading. The badge retries on its own.
local score and a numberAn on-device signal from 0 to 100 on the badge. It may suggest whether the content could be AI-generated. It is a signal, not a verdict.
unavailableNo score. The model failed, the image could not be read, or a prefilter skipped it. The reason is in the tooltip. The badge does not fill in a stand-in number.

Load unpacked

For development from the source repository. This is not a store install, and there is no store listing to add.

  1. Open chrome://extensions, turn on Developer mode, choose Load unpacked, and select the chrome_plugin/ folder from a checkout of the repository.
  2. Serve the sample page over http. Enable does not work on file://.
  3. Open the sample page, then choose Enable badges on this site and allow it.

Support

LucidScan is maintained by Alex Stevens. Write to GitHub issues. The same notes are on the support page.

A surprising score

A score is an uncalibrated local signal. If one looks wrong for what you were reading, open an issue with your Chrome version, the site's host (leave off private query strings), the badge text, and whether the popup still showed a model download. Include the selected text only if you mean to publish it. There is no telemetry, so the report is the only copy of what you saw.

Limits

  • Cross-origin frames are skipped unless that origin is enabled on its own.
  • A cross-origin image that taints the canvas is requested again by URL. If that fails, the badge says unavailable.
  • The first run downloads about 435 MB from Hugging Face.
  • Both bundled models are English-centric.
  • An optional right-click item can talk to a program you run at localhost:5000. Ordinary badges do not use it. It is proposed for removal before any public submission.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
